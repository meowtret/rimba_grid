name=Rimba Grid
qgisMinimumVersion=3.16
qgisMaximumVersion=4.99
description=Grid koordinat Print Layout berlabel BT/BB dan LU/LS (Indonesian-style map grid labels).
about=Membuat atau mengubah grid geografis pada item peta di Print Layout dengan label gaya Indonesia: Bujur Timur/Bujur Barat (BT/BB) dan Lintang Utara/Lintang Selatan (LU/LS), misalnya 122°56'00" BT dan 0°42'00" LS. Label disimpan sebagai ekspresi grid kustom, sehingga layout tetap tampil benar walau dibuka tanpa plugin. Fitur: format DMS/DM/desimal, interval otomatis, bingkai zebra/tick, label vertikal di sisi kiri-kanan, dan mode "hanya ganti label" untuk grid yang sudah ada.
 English: Creates or updates geographic map grids in Print Layouts with Indonesian hemisphere labels (BT/BB = east/west longitude, LU/LS = north/south latitude).
